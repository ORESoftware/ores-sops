# v0.5 environment + execution-profile overlay

Tracking: #40.

Deployment environment remains exactly `dev | stage | prod`. Execution profile is orthogonal: `local | gha | gha-indie-worker | test`. Profiles are not additional deployment environments.

Effective configuration is composed as canonical environment ciphertext plus a profile overlay. A profile may override only keys explicitly marked overridable by the admitted manifest/schema; unknown collisions fail closed. Secret/bootstrap identities are never stored in the ciphertext set they unlock.

TypeSpec and independently authored Draft 2020-12 JSON Schema describe key name, type/format, requiredness, secrecy, environment scope, allowed profiles, override permission, diagnostic exposure, and rename/deprecation metadata. Tooling may audit key names/structure without disclosing values.

Recipient separation remains environment/profile scoped. Fork PRs cannot decrypt protected material, plaintext stays runtime-only/ignored, and rendered effective environments must never enter caches, artifacts, logs, issues, or source control.
